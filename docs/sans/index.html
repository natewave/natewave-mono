02

Tell them apart

The Mono's distinctions, kept in prose

Many sans designs draw I, l and 1 as the same bar. Natewave Sans keeps every distinction the Mono makes, because the research behind them comes from proportional prose in the first place. Only the serifs that existed to fill a monospace cell are gone.

Il1|

I has bars, l a tail, 1 a flag and a foot, and | is a plain rule. Line ends carry most of what identifies a letter.

moderate Fiset et al., 2008

0Oo

Zero keeps the Mono's dot and narrower oval, so codes and IDs read the same in both families.

requirement Unicode UTS #39 on confusables

ij!

i keeps a short tail, which makes it wider than a bare stroke and unlike l. The dots are 10% larger.

moderate Beier & Larson, 2010

rn m

Widths separate them now: rn is a third wider than m, and cl two thirds wider than d.

convention proportional spacing

9gq

A double-storey g breaks the g, q, y look-alike group of descending letters.

moderate Bernard et al., 2016

8B3

A flat-topped 3 stays clear of 8 and B, as in the Mono.

convention JetBrains Mono

.,;:

Periods and commas are 15% larger than Iosevka's default, so sentence ends survive small sizes.

convention Input, Source Code Pro

a*†

The asterisk sits high, where a footnote mark belongs. The Mono centres it on the operator axis for code.

convention prose typesetting

11 px loupe

Drawn live by your browser at 11 px on a 1× pixel grid, then magnified without smoothing. Below this size, prefer Natewave Mono: fixed pitch reads better near the acuity limit.

03

Spaced in sixths

Measured live from the font

Iosevka builds proportional families by giving each glyph a width in sixths of the Mono's 600-unit cell. Narrow letters drop to 4/6, wide ones grow to 8/6 or 9/6, and most stay at 6/6, which keeps the Mono's letterforms intact. The space shrinks to 350 units. Each box below is one glyph's full advance width.

Natewave Mono –

Proportional spacing earns its keep in running text. Spaces shrink to 350 units, i and l to 400, and the line gets shorter, so the eyes need fewer jumps to cover the same words. The gain fades near the acuity limit, where the even rhythm of a monospace reads better.

04

Made to pair with the Mono

One set of vertical metrics

Both families share every vertical metric: x-height, cap height, ascenders, descenders and line height. Code set in Natewave Mono needs no size correction inside Natewave Sans text, and a mixed line keeps one baseline and one x-height.

Reading code isn't reading prose

Most legibility studies tested prose, so Natewave Sans takes their findings directly, while Natewave Mono extrapolates them to code. Set text in the Sans, and keep code, kbd and pre in the Mono: at the same font-size, their x-heights match.

$ fc-list : family | grep Natewave
Natewave Mono
Natewave Sans

Regular is drawn a little heavier than Iosevka's, because boldness helps at small sizes. The italic is mostly oblique, with cursive a and f, and italics read slightly slower (Tinker & Paterson, 1928), so keep them for emphasis. Old-style figures sit better in running text; the default lining figures are all the same width, so they line up in tables.

What Iosevka v34.4.0 can't do

  • No kerning: Iosevka only positions marks, so pairs like To, AV, Ty and r, keep their full gaps.
  • Widths come in sixths, not letter by letter: most lowercase letters share 600 units, so f, r and t set looser than in a hand-spaced sans.
  • The openings of c, e and s are the Mono's, so they stay fairly closed for a text face.

Install

Unhinted TTF, for macOS and high-DPI screens

The download on this page is the unhinted TTF build of the current build plan. Hinted TTFs suit Windows and 1× Linux screens: build them with the ttf::NatewaveSans target (see Build from source), or get them from GitHub Releases once a version is published.

Unzip the download, then double-click each .ttf and choose Install, or copy them into your fonts folder:

cp NatewaveSans/*.ttf ~/Library/Fonts/

If the family doesn't show up in Font Book or your apps, remove the four files from ~/Library/Fonts and install them again, then restart the app.

Copy the fonts into your user font folder and refresh the font cache:

mkdir -p ~/.local/share/fonts/NatewaveSans
cp NatewaveSans/*.ttf ~/.local/share/fonts/NatewaveSans/
fc-cache -f
fc-list : family | grep "Natewave Sans"

Unzip the download, select the four .ttf files in File Explorer, right-click and choose Install (or Install for all users). On a standard-density screen a hinted TTF renders crisper; see the note above.

Build it yourself from the repository root with Node.js and Git (add ttfautohint for hinted targets). One build plan holds both families:

git clone --depth 1 --branch v34.4.0 https://github.com/be5invis/Iosevka.git
cp private-build-plans.toml Iosevka/
cd Iosevka && npm install
npm run build -- --jCmd=4 webfont-unhinted::NatewaveSans
